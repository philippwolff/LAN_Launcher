LAN PARTY LAUNCHER – KURZANLEITUNG
Stand: 31.10.2026

1. PROJEKT / GITHUB
Repository: https://github.com/philippwolff/LAN_Launcher
Lokaler Projektordner (Beispiel): C:\Projekte\LAN_Launcher\LAN_Launcher
GitHub Desktop: "Fetch origin" und "Pull origin" laden Änderungen herunter.
Eigene Änderungen: "Commit to main" und "Push origin" hochladen.
WICHTIG: Hochgeladene Spiele und Serverdaten NICHT in Git committen.

2. VORAUSSETZUNGEN
Windows, .NET 10 SDK (für Entwicklung/Build), GitHub Desktop.
Der Launcher ist eine WPF-Anwendung in C#; der Server nutzt ASP.NET Core.

3. SERVER STARTEN (ENTWICKLUNG)
Eingabeaufforderung (cmd) im Projektordner öffnen:
  set "LANLAUNCHER_AdminKey=HIER_EIGENEN_SCHLUESSEL_EINTRAGEN"
  dotnet run --project src/LanLauncher.Server
Der Admin-Schlüssel wird nur für die Serverlaufzeit gesetzt.
Serveradresse auf dem gleichen PC: 127.0.0.1:8080
Für andere PCs: LAN-IP des Server-PCs und Port 8080 verwenden.
Server mit Strg+C beenden.

4. SERVER ALS EXE STARTEN
Im Projektordner "Server-EXE-erstellen.cmd" doppelklicken.
Die erzeugte EXE liegt unter Server\LanLauncher.Server.exe.
"Server-starten.cmd" startet sie und fragt nach dem Admin-Schlüssel.
Der Ordner Server\ ist lokal und wird nicht nach GitHub übertragen.

5. LAUNCHER STARTEN (ENTWICKLUNG)
Zweite Eingabeaufforderung im Projektordner:
  dotnet run --project src/LanLauncher.Client
Server-IP/Port und Benutzernamen eintragen, dann "Verbinden".
Über "⚙ Einstellungen" die Standardordner für Installation und Download
festlegen. Die Einstellungen werden pro Windows-Benutzer gespeichert unter:
  %LOCALAPPDATA%\\LANLauncher\\settings.json
Standardinstallation: %LOCALAPPDATA%\\LANLauncher\\Games
Standarddownload: %USERPROFILE%\\Downloads
Bei "Herunterladen und installieren" wird der Standardinstallationsort
automatisch genutzt; ZIP-Spiele erhalten einen Unterordner mit Spielnamen.
Downloads für die Installation werden zunächst als temporäre .part-Dateien
im Standarddownloadordner abgelegt und nach Verarbeitung entfernt.
"Nur Paket herunterladen" öffnet weiterhin den Speichern-Dialog, der im
eingestellten Downloadordner startet.
Die Spielerübersicht zeigt derzeit verbundene Benutzer.

6. ADMIN / SPIELE HOCHLADEN
Den gleichen Admin-Schlüssel wie beim Serverstart im Launcher eintragen.
Spielname und Version angeben, "ZIP/EXE hochladen" auswählen.
Alternativ Dateien in den Serverordner Games\Inbox kopieren,
"Server-Inbox prüfen" klicken und "Aus Inbox importieren" wählen.
ZIP/EXE-Upload und Download zeigen ein Fortschrittsfenster mit Prozenten.
"Abbrechen" beendet eine laufende Übertragung; beim Schließen des Clients
erscheint eine Sicherheitsabfrage (Ja = schließen und Übertragungen\nabbrechen; Nein = Launcher geöffnet lassen). Unvollständige
Downloads werden als .part-Dateien gespeichert und bei Abbruch gelöscht.
Bereits vorhandene .part-Dateien von älteren Versionen ggf. manuell löschen.
Ein Spiel in der Bibliothek anklicken: Es öffnet sich ein Aktionsfenster
mit "Starten", "Herunterladen und installieren", "Nur Paket herunterladen"
und "Vom Server löschen (Admin)".
"Starten" öffnet die bekannte Spiel-EXE. Ist noch keine hinterlegt,
kannst du einmalig eine lokale EXE auswählen. Die Zuordnung wird in
den lokalen Einstellungen gespeichert. Nach ZIP-Installation wird eine
erkannte/ausgewählte EXE automatisch als Startpfad hinterlegt.
NEU: "Herunterladen und installieren" lädt das gewählte Spiel herunter.
- ZIP: Installationsbasisordner auswählen; ZIP wird automatisch in einen
  neuen Unterordner mit dem Spielnamen entpackt. Anschließend sucht der
  Launcher nach EXE-Dateien. Bei einer EXE wird deren Start angeboten;
  bei mehreren EXE-Dateien wählst du die richtige aus. Vor dem Start
  muss die Ausführung ausdrücklich bestätigt werden.
- EXE: Installationsbasisordner auswählen; nach dem Download fragt der
  Launcher ausdrücklich, ob der normale Installationsassistent gestartet
  werden soll. Eine stille/unbeaufsichtigte Installation erfolgt nicht.
- Unvollständige Downloads werden entfernt. Bereits vorhandene Dateien
  im Installationsordner werden nicht überschrieben.
- Die Installation registriert derzeit noch keinen Spielstart im Launcher.
SPIEL LÖSCHEN (ADMIN): Spiel in der Bibliothek anklicken, im Popup
"Spiel vom Server löschen (Admin)" anklicken und Warnung bestätigen.
Dies entfernt den Bibliothekseintrag und das Paket aus Packages\ dauerhaft.
Der Admin-Schlüssel muss gültig sein. Bereits heruntergeladene Dateien
auf anderen PCs sowie Dateien in Inbox\ bleiben erhalten.

7. SPEICHERORTE AUF DEM SERVER
C:\LAN_Launcher_Server\Games\
  Packages\  = hochgeladene ZIP-/EXE-Pakete
  Inbox\     = Dateien für manuellen Import
  games.json  = gespeicherte Spieleinformationen
Der Server erstellt benötigte Ordner automatisch.
Wurden Spiele vor der Umstellung hochgeladen, müssen Packages und
games.json aus dem bisherigen Storage-Ordner einmalig kopiert werden.
Den alten Ordner erst nach erfolgreicher Prüfung löschen.

8. WICHTIGE HINWEISE / NOCH OFFEN
- EXE-Installationsassistenten können nach Download und Bestätigung gestartet
  werden; deren Installationsablauf und Zielverzeichnis bestimmt der Installer.
- ZIP-Archive werden automatisch entpackt und können nach Bestätigung
  eine enthaltene EXE starten; automatischer Spielstart ohne Rückfrage,
  Installationserkennung und Versionsabgleich folgen später.
- Ganze entpackte Spieleordner werden noch nicht automatisch importiert.
- Admin-Zugriff ist derzeit über einen Schlüssel geschützt; HTTP im LAN
  ist nicht verschlüsselt. Nur in einem vertrauenswürdigen LAN einsetzen.
- Nur Spielepakete verteilen, für die entsprechende Nutzungsrechte bestehen.
- Bei Fehlern die vollständige Konsolenausgabe bzw. Fehlermeldung sichern.
